#Execução do Projeto

mount c <path or the project >
Exemplo: mount c: F:\Neo_Bertiogo usado pela equipe

mount c F:\Pacman

c:

tasm base.asm

tlink base.obj

base

#Como Jogar

No Menu basta usar as setas para cima (up arrow) e para baixo (dow arrow) e pressionar a opção desejada através da tecla enter
Após isso deve se usar as setas para esquerda (left arrow) e para direita (right arrow) para confirmar ou rejeitar a passagem respectivamente
No fim basta clicar qualquer botão para seguir de fase e repetir isto sucessivamente até atingir à vitória
